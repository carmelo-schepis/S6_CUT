- **MoneyPrinterTurbo** — MIT, commit `1d1d0d25b3c27609be4683c0cf3dc08c5821788a`. Topic-to-video stages (reviewable script, material keywords, narration, captions, composition, and bounded variants) were used as behavioral reference only; no source code, music, fonts, logos, or demo assets were copied.

No source code was copied from the reference repositories during this build. The following local resources informed clean implementation at a behavioural/architectural level:

- **ClippyMe** — MIT. Reviewed its local `S6_CUT_TAKEAWAYS.md` plus documented concepts for TextTiling, boundary cleanup, independent clips, job recovery, composition order, QA, and security. The local resource checkout does not expose Git revision metadata; no direct source file was copied.
- **ReelsGenerator** — MIT. Reviewed modular Script/TTS/cache/pacing concepts through `S6_CUT_TAKEAWAYS.md`; no direct source file was copied.
- **ViralMint** — AGPL-3.0. Reviewed provider abstraction, score explainability, storyboard, provider health, and test-taxonomy concepts through `S6_CUT_TAKEAWAYS.md`; no direct source file was copied.
- **VUZA Free AI Video Creator** — MIT. Reviewed resolver fallback and progressive gallery concepts through `S6_CUT_TAKEAWAYS.md`; Pinterest scraping and rights-unknown media behavior were explicitly excluded.
- **AI YouTube Shorts Generator** — reference-only because the supplied copy lacks a verified licence/revision. No code was copied.
- **yt-dlp** — Unlicense/public-domain dedication and third-party component notices in the bundled project. S6_cut installs release `2026.7.4` as a constrained, user-authorised YouTube import dependency and does not vendor its source.

- **Anton**, **Archivo Black**, **Barlow**, **Montserrat**, **Lora**, and **Bodoni Moda** — SIL Open Font License 1.1. Vendored under `engine/fonts/` (each family with its own `OFL.txt`) and installed into the engine image. Montserrat's pinned static ExtraBold Italic face is used for Smart speech captions; the existing Montserrat Bold face remains unchanged for AI hooks. Bodoni Moda is the upstream variable TTF; its default `opsz=14`, `wght=400` axes are retained until production libass confirms other static instances. The Bodoni notice is also served beside the web font at `web/public/fonts/bodoni_moda/OFL.txt` and matches the upstream Bodoni repository revision recorded in `third_party_provenance.json`.
- **Microsoft Fluent Emoji 3D PNG library** — MIT, pinned at `microsoft/fluentui-emoji` commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`. A curated set of 32 unmodified transparent 3D PNGs is vendored under `engine/assets/fluent-emoji/`, with the upstream MIT `LICENSE`, per-file SHA-256 checksums, dimensions, complete Unicode sequences, stable identifiers, and names in `manifest.json`. Coverage includes every current automatic `_EMOJI_CANDIDATES` value, 😩, common faces/reactions/hearts/gestures, 👍🏽, 👩‍💻, and 👩🏽‍💻. This is a curated subset, not complete Unicode coverage. `scripts/import_fluent_emoji.py` reproduces the selected assets from that exact upstream revision; `scripts/validate_fluent_emoji.py` checks manifest integrity. Runtime resolution is local and exact-sequence only.
- **Roboto Condensed Light** — Apache License 2.0, vendored as a pinned static `RobotoCondensed-Light.ttf` from `andreasf/Roboto` commit `199ca7fcf1f0606106f8a93d13e42245729f9fcb`. Static weight 300 avoids variable-axis ambiguity. The three reference web preview faces are served from local `web/public/fonts/`; there are no external font requests.
- **Oswald** and **Gaegu** — SIL Open Font License 1.1, pinned to `google/fonts` commit `45e3d5269e4a17d823f6d84470bc084dc5ae46f6`. Oswald Regular is a deterministic static `wght=400` instance generated from the upstream variable font (see `scripts/build-music-fonts.py`), so libass never picks a variable axis; Gaegu Bold is the unmodified upstream file. Both power the Music condensed and handwritten lyric themes, and are separate families so no existing theme's resolved font changes. Their web preview faces in `web/public/fonts/` are Latin subsets served locally, with no external font requests.
- Barlow, Montserrat, Lora, Bodoni Moda, and Roboto Condensed files are unmodified upstream assets. Font names and Reserved Font Names are untouched. See `third_party_provenance.json` for source URLs, pinned revisions, and checksums.
